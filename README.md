# OCR Application

> **Быстрый запуск (Инструкция по сборке)**
> 1. Убедитесь, что у вас установлен **JDK 17** или выше.
> 2. Склонируйте репозиторий: `git clone https://github.com/FelixWinchester/ваш_репозиторий.git`
> 3. Перейдите в папку проекта: `cd ваш_репозиторий`
> 4. Выполните сборку через Gradle Wrapper:
>    * **Windows:** `gradlew.bat assembleDebug`
>    * **Linux/macOS:** `./gradlew assembleDebug`
> 5. Готовый APK файл будет находиться в директории: `app/build/outputs/apk/debug/`

## Patch 0.0.1: Инициализация проекта и базовый UI

В данном обновлении заложена основа архитектуры Android-приложения и реализован первичный графический интерфейс для модуля распознавания текста (OCR).

### Основные изменения
* **Структура проекта**: Сформирована иерархия пакетов. Подключены необходимые зависимости в централизованном каталоге `libs.versions.toml`.
* **Интерфейс пользователя**: Создан экран выбора изображений с использованием Jetpack Compose. Реализована логика взаимодействия с кнопкой активации распознавания.
* **Ресурсы**: Выполнена первичная настройка цветовой палитры и текстовых констант в директории `res/values`.
* **Технический стек**: Проект переведен на использование Kotlin DSL (`.gradle.kts`) для управления сборкой.
